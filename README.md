# 低空云平台

基于 Web 的低空飞行管理平台，提供无人机航线规划、仿真飞行、空域申请与计算、飞行报告等功能。

![image-20250801134512325](https://cdn.jsdelivr.net/gh/binwenwu/picgo_01/img/image-20250801134512325.png)

## 快速开始

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 主要功能

- 三维地图与可视化
- 手动 / 自动航线规划
- 航线管理与仿真飞行
- 空域申请与空域计算
- 飞行报告
- 机型管理
